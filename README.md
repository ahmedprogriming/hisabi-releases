# حسابي — تحميل التطبيق

📲 **للهواتف:** [hisabi-arm32.apk](https://github.com/ahmedprogriming/hisabi-releases/releases/download/v1.0.1/hisabi_v2.0.1-arm64.apk)

## طريقة التثبيت
1. افتح الرابط من Chrome واضغط تنزيل.
2. فعّل "السماح بالتثبيت من هذا المصدر" إن طُلب منك.
3. عند تنبيه Play Protect: المزيد من التفاصيل ← التثبيت على أي حال.

للدعم والتجربة المجانية: واتساب [رقمك]
